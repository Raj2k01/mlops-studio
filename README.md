# MLOps Studio

An end-to-end Machine Learning platform built using:

- Spring Boot 4
- React + TypeScript
- Python + XGBoost
- AWS SageMaker
- Amazon S3
- CloudWatch
- EventBridge
- SNS

## Status

- [x] Project Initialization
